# Ревью GAS-версии бота (Sheets + Apps Script)

Порт того же салона красоты на Google Apps Script + Google Sheets вместо Node/Postgres.
Функционал 1:1 с текущим ботом: визард записи, админ-панель (мастера/услуги/часы), напоминания через time-trigger, сессии визардов в PropertiesService вместо Telegraf Scenes.

**Статус:** все фичи оставлены как есть (это осознанный выбор — MVP по фичам не режем), 3 бага ниже исправлены. Актуальный код лежит в [`gas/`](gas/) как файлы, готовые к `clasp push`.

## Баги — исправлены в `gas/`

1. **WEBHOOK_SECRET генерировался, но нигде не проверялся.**
   Apps Script не даёт `doPost(e)` доступа к HTTP-заголовкам запроса, поэтому стандартный `secret_token`-заголовок Telegram проверить нельзя. Вместо этого секрет теперь зашивается в URL вебхука как query-параметр (`setupWebhook` в `Setup.gs` добавляет `?secret=...` к deployment URL перед вызовом `setWebhook`), а `doPost` в `Code.gs` через `isValidWebhookRequest_()` сверяет `e.parameter.secret` с сохранённым значением и молча игнорирует все остальные запросы.

2. **Markdown в пользовательских данных не экранировался.**
   Добавлена `escMd_()` в `Config.gs` (экранирует `_ * \` [`) и применена везде, где в текст с `parse_mode: 'Markdown'` подставляются имя/фамилия/юзернейм клиента, имя мастера, название/описание услуги — в `Start.gs`, `MyBookings.gs`, `Admin.gs`, `Booking.gs`, `AddMaster.gs`, `AddService.gs`, `Reminders.gs`. Кнопки (callback-текст) не трогал — Telegram их как Markdown не парсит, экранировать там нечего.

3. **Два независимых источника часового пояса.**
   `getConfig_().TIMEZONE` теперь всегда возвращает `Session.getScriptTimeZone()` — то есть значение из `appsscript.json`, а не отдельно хранимый Script Property. Второго места, где таймзону можно было бы выставить иначе, больше не существует, так что `combineDateTime_` и `todayStr_`/`formatDate*_` физически не могут разъехаться. `setConfig()` в `Setup.gs` больше не принимает `timezone`-параметр — часовой пояс меняется через `appsscript.json` (или Project Settings → General → time zone в редакторе).

## Некритичные заметки

- Чтение целого листа на каждый вызов `Db.*` — нормально при заявленном масштабе (несколько мастеров, десятки записей/день), но не переживёт рост на порядок.
- Сессии визардов (`sess_<userId>`) не чистятся при незавершённом визарде — не страшно, ограничено количеством уникальных пользователей.

## Слишком длинно/сложно для MVP?

Нет — для того функционала, который он реализует (запись клиента + админ-консоль в Telegram + напоминания), код довольно компактный: без фреймворка, плоские файлы, простой паттерн "массив шагов" вместо Telegraf Scenes. Это честный 1:1 порт текущего Node-бота, а не оверинжиниринг ради оверинжиниринга.

Решение: все фичи (админка в Telegram, напоминания и т.д.) оставлены как есть — MVP здесь про "просто работает", а не "меньше функций".

## Как задеплоить (`gas/`)

1. `clasp create` / `clasp clone` в этой папке (или вручную создать проект в script.google.com и вставить файлы) и `clasp push`.
2. В редакторе Apps Script выполнить `setConfig('<BOT_TOKEN>', '<admin_id1,admin_id2>')` — сохранит токен, админов и сгенерирует `WEBHOOK_SECRET`.
3. Deploy → New deployment → Web app, скопировать URL.
4. Выполнить `setupWebhook('<URL из шага 3>')` — сама пропишет секрет в URL вебхука.
5. Выполнить `createSheets()` — создаст все листы и счётчики.
6. Выполнить `setTriggers()` — поставит триггер напоминаний каждые 5 минут.
7. Если нужен часовой пояс отличный от `Asia/Bishkek` — поменять `timeZone` в `gas/appsscript.json` до `clasp push`.
