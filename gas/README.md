# Бот салона красоты (GAS-версия) — как всё работает

Порт Node-бота на Google Apps Script + Google Sheets вместо базы данных.
Деплой и техническую сторону см. в [`../GAS_REVIEW.md`](../GAS_REVIEW.md).

## Для клиента

- **/start** — приветствие и главное меню: «✂️ Записаться» / «📋 Мои записи».

- **Записаться** — мастер записи из 5 шагов:
  1. Выбор услуги (название, цена, длительность).
  2. Выбор мастера, который её оказывает.
  3. Выбор даты (ближайшие 14 дней, только те, где у мастера есть рабочие часы).
  4. Выбор свободного времени (уже с учётом длительности услуги и занятых слотов).
  5. Подтверждение — после «✅ Подтвердить» запись создаётся, клиент получает номер записи, админы получают уведомление с кнопкой отмены.
  «❌ Отмена» доступна на любом шаге.

- **Мои записи** — список активных записей клиента с кнопкой «❌ Отменить» на каждую (с подтверждением «да/нет»).

- **Напоминания** — бот сам присылает сообщение за 24 часа и за 1 час до визита (проверка идёт раз в 5 минут по триггеру).

## Для админа

Доступ есть только у Telegram-ID, перечисленных в `ADMIN_IDS` (Script Properties). Обычным пользователям команда `/admin` отвечает «⛔ Нет доступа».

- **/admin** — открывает панель:
  - «📅 Сегодня» / «📅 Завтра» / «🗓 По дате» — расписание на день с кнопкой отмены записи под каждой строкой.
  - «📋 Все предстоящие» — все будущие записи разом.
  - «👩 Мастера» — список мастеров, активировать/деактивировать, назначить услуги, задать рабочие часы по дням недели; «➕ Добавить мастера».
  - «💅 Услуги» — список услуг, активировать/деактивировать; «➕ Добавить услугу».

- **Отмена записи** (и клиентом, и админом) — только меняет статус на «отменена», строка в таблице не удаляется.

## Как добавить/убрать админа

Код не трогаем — правим значение прямо в Apps Script:
**Project Settings (⚙️) → Script Properties → `ADMIN_IDS`** — список ID через запятую.

## Где хранятся данные

Google-таблица, привязанная к скрипту (Users, Masters, Services, MasterServices, WorkingHours, Appointments, Counters — листы создаёт `createSheets()`). Открыть таблицу и посмотреть/поправить данные руками можно в любой момент — в этом главное отличие от Node+Postgres версии.
